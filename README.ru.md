# Маркеры Audition для Subtitle Edit Classic

**Экспорт субтитров в CSV-маркеры Adobe Audition одним нажатием. Python не нужен.**

[Скачать](https://github.com/BrainDeLook/subtitleedit-audition-markers/releases/latest) · [English](README.md) · [История изменений](CHANGELOG.md) · [Subtitle Edit Classic](https://github.com/BrainDeLook/subtitleedit-classic)

Отдельный DLL-плагин для Windows Forms Classic. Основан на сценарии работы DeCoCo Converter 1.4, но написан на C# и берёт текущие реплики из редактора, включая несохранённые изменения. Исходные субтитры и историю отмены он не изменяет.

## Установка

1. Скачайте `AuditionMarkers-1.0.0.zip` из Releases и распакуйте.
2. Дважды нажмите `Install.cmd` либо скопируйте `AuditionMarkers.dll` в `%APPDATA%\Subtitle Edit\Plugins`. Для portable-версии используйте её собственную папку `Plugins`.
3. Перезапустите Classic. Команда появится в **Инструменты → Маркеры Audition**. Горячую клавишу можно назначить в **Параметры → Настройки → Горячие клавиши → Плагины**.

При первом экспорте откроются настройки. Затем файл создаётся сразу, а путь показывается в строке состояния. Python, модели и API-сервисы не требуются.

### Быстрая кнопка

Кнопка **Маркеры Audition** со стрелкой настроек требует дополнения хоста Classic: локальная сборка 4.0.28.5 либо последующая сборка с этой поддержкой. Основная часть кнопки экспортирует, стрелка открывает настройки.

Опубликованный установщик Classic 4.0.28.4 поддерживает плагин через меню и горячую клавишу, но ещё не передаёт выбор строк и не создаёт кнопку. Для этой конкретной версии на странице релиза плагина есть отдельный дополнительный пакет `ClassicToolbar-4.0.28.5.zip`. Его скрипт проверяет исходный EXE, создаёт копию для отката и заменяет только EXE. Это дополнение к обычному установщику Classic; зависимости оно не заменяет. Исходники поддержки кнопки находятся в [репозитории Classic](https://github.com/BrainDeLook/subtitleedit-classic).

## Как работает экспорт

Для `episode.ass` создаётся `episode_audition.csv` рядом с субтитрами. При повторном нажатии — `episode_audition_1.csv` и далее. Старые файлы не перезаписываются. Можно запомнить другую папку. Для документа без имени плагин один раз спросит папку экспорта. Недоступная папка вызывает понятную ошибку, без скрытого сохранения в другое место.

| Настройка | По умолчанию |
| --- | --- |
| Вид маркеров | Точечные в начале реплик, как в исходном скрипте |
| Диапазоны | По желанию: длительность от начала до конца реплики |
| Название | «Маркер 1», «Маркер 2»… либо текст реплики |
| Описание | Текст без тегов, переносы строк заменены пробелами |
| Реплики | Все; режим «только выбранные» требует обновлённого хоста |
| Папка | Рядом с субтитрами либо выбранная постоянная папка |

Файл имеет расширение `.csv`, но поля разделены **табуляцией**:

```text
Name    Start    Duration    Time Format    Type    Description
```

Используются `decimal`, тип `Cue`, минуты/секунды/миллисекунды и UTF-8 без BOM, как в приложенном конвертере. Кавычки экранируются. Пересекающиеся реплики остаются отдельными маркерами; время не меняется. Порядок соответствует документу.

## Проверка в Audition

Откройте соответствующий звук или сессию и выберите **File → Import → Markers from CSV**. Проверьте несколько позиций, кириллицу и границы диапазонов. Плагин экспортирует только маркеры: он не переносит звук, не создаёт аудиоклипы и не управляет Audition.

Проверены реальные CSV и запуск из Classic. Импорт непосредственно в Adobe Audition для этого релиза остаётся ручной проверкой. Структура файла сохранена по вашему конвертеру DeCoCo.

## Настройки и удаление

Настройки хранятся в `Plugins\AuditionMarkers.settings.xml` внутри папки данных Classic. Общий `Settings.xml` не меняется; горячая клавиша по умолчанию не назначается во избежание конфликтов.

Для удаления закройте Classic и удалите `AuditionMarkers.dll`. Чтобы сбросить настройки, удалите и XML плагина. Экспортированные CSV сохраняются.

## Сборка

На Windows с .NET Framework 4.8 и установленным Classic:

```powershell
./build.ps1 -ClassicDirectory 'C:\Program Files\Subtitle Edit Classic' -Test
```

Результат — `dist\AuditionMarkers.dll`. NuGet и Python не нужны. Тесты проверяют форматы, тайминги, кавычки, выбранные строки и безопасность записи. `tests/HostIntegration.cs` — проверка кнопки в обновлённом Classic; запускать только с изолированными тестовыми данными.
