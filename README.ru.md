# Маркеры Audition для Subtitle Edit Classic

**Экспорт субтитров в CSV-маркеры Adobe Audition одним нажатием. Python не нужен.**

[Скачать](https://github.com/BrainDeLook/subtitleedit-audition-markers/releases/latest) · [English](README.md) · [История изменений](CHANGELOG.md) · [Subtitle Edit Classic](https://github.com/BrainDeLook/subtitleedit-classic)

Отдельный DLL-плагин для Windows Forms Classic. Основан на сценарии работы DeCoCo Converter 1.4, но написан на C# и берёт текущие реплики из редактора, включая несохранённые изменения. Исходные субтитры и историю отмены он не изменяет.

## Установка

1. Скачайте `AuditionMarkers-1.2.1.zip` из Releases и распакуйте.
2. Дважды нажмите `Install.cmd` либо скопируйте `AuditionMarkers.dll` в `%APPDATA%\Subtitle Edit\Plugins`. Для portable-версии используйте её собственную папку `Plugins`.
3. Перезапустите Classic. Команда появится в **Инструменты → Маркеры Audition**. Горячую клавишу можно назначить в **Параметры → Настройки → Горячие клавиши → Плагины**.

При первом экспорте откроются настройки. Затем файл создаётся сразу, а путь показывается в строке состояния. Python, модели и API-сервисы не требуются.

### Версия 1.2: выбор актёров и метки внутри MP4

Это расширение того же необязательного **Audition Markers**, второй плагин не нужен. Быстрая кнопка по-прежнему экспортирует CSV.

В настройках выберите **Все реплики**, **Выделенные строки** или **Выбранные актёры**. Актёры берутся из поля ASS/SSA «Актёр»; есть отдельный пункт **«Без актёра»**. Имена из текста не угадываются. Можно отметить несколько актёров. Отбор влияет только на метки: остальные субтитры продолжают вшиваться в видео. Нумерация `Маркер 1 (25)` доступна и для отбора по актёрам.

Для передачи актуального списка актёров и автоматической обработки хардсаба установите дополнение **ClassicHost-4.0.28.6.zip** из этого релиза. Оно принимает только проверенные EXE 4.0.28.4 и 4.0.28.5 и сохраняет копию для отката. Это поддержка плагина в Classic, не второй плагин. Без Audition Markers в хардсабе нет элемента меток и записи метаданных.

В хардсабе выберите MP4 и включите **«Метки Audition (MP4)»** в блоке аудио. Кнопка `…` рядом открывает настройки плагина. После успешного рендера плагин записывает Adobe XMP-маркеры типа Cue внутрь файла видео. Отдельные CSV/XMP-файлы не требуются. При обрезке время меток сдвигается и ограничивается длительностью результата; исходный номер строки сохраняется. При выключенной галочке экспорт работает как раньше. Если встраивание включено, пакетный режим и другие контейнеры пока отклоняются до начала кодирования.

В настройках есть **«Метки в готовый MP4…»**: создаётся отдельная копия `<видео>_audition.mp4`, исходный файл и существующие результаты не перезаписываются. Для этого действия используются текущие поля окна; нажмите «Сохранить», чтобы запомнить их для следующих экспортов.

Запись потоковая, с отменой, временным файлом рядом с результатом и атомарной заменой. Для автоматического встраивания нужно свободное место примерно под ещё одну копию видео; для отдельной ручной копии — больше. Чужие свойства и дорожки XMP сохраняются; при повторной записи заменяется только дорожка нашего плагина. Повреждённые/неоднозначные XMP и файлы с внутренним форматом QuickTime отклоняются без перезаписи.

**Проверено в Adobe Audition 2026:** откройте нужный звук или многодорожечную сессию, нажмите **File → Import → Markers from File… (Alt+/)** и выберите MP4 с метками. Метки импортируются в активный документ. Простое открытие/добавление видео не переносит их в сессию. Проверены выбранные метки с кириллицей, исходными номерами и временем, а также тестовый диапазон. Обычные главы MP4 вместо Adobe-маркеров не используются.

**Обновление с 1.2.0:** в этой версии был ошибочный идентификатор XMP, из-за которого Audition не находил метки. Установите 1.2.1 и используйте **«Метки в готовый MP4…»** с нужным выбором реплик: будет создана исправленная копия без перекодирования видео/звука.

### Быстрая кнопка

Кнопка **Маркеры Audition** со стрелкой настроек требует дополнения хоста Classic: локальная сборка 4.0.28.5 либо последующая сборка с этой поддержкой. Основная часть кнопки экспортирует, стрелка открывает настройки.

Опубликованный установщик Classic 4.0.28.4 поддерживает плагин через меню и горячую клавишу, но ещё не передаёт выбор строк и не создаёт кнопку. На странице текущего релиза есть дополнение `ClassicHost-4.0.28.6.zip` для проверенных EXE Classic 4.0.28.4 / 4.0.28.5. Его скрипт проверяет исходный EXE, создаёт копию для отката и заменяет только EXE. Это дополнение к обычному установщику Classic; зависимости оно не заменяет. Исходники поддержки кнопки находятся в [репозитории Classic](https://github.com/BrainDeLook/subtitleedit-classic).

## Как работает экспорт

Для `episode.ass` создаётся `episode_audition.csv` рядом с субтитрами. При повторном нажатии — `episode_audition_1.csv` и далее. Старые файлы не перезаписываются. Можно запомнить другую папку. Для документа без имени плагин один раз спросит папку экспорта. Недоступная папка вызывает понятную ошибку, без скрытого сохранения в другое место.

| Настройка | По умолчанию |
| --- | --- |
| Вид маркеров | Точечные в начале реплик, как в исходном скрипте |
| Диапазоны | По желанию: длительность от начала до конца реплики |
| Название | «Маркер 1», «Маркер 2»… либо текст реплики |
| Описание | Текст без тегов, переносы строк заменены пробелами |
| Реплики | Все; режим «только выбранные» требует обновлённого хоста |
| Папка | Рядом с субтитрами либо выбранная постоянная папка |

В режиме **«Только выбранные реплики»** можно включить **«Нумерация с 1, исходный номер в скобках»**: получится `Маркер 1 (25)`, `Маркер 2 (38)` и далее. В скобках — номер строки в документе, без дополнительных слов. По умолчанию настройка выключена, чтобы сохранить прежнее поведение. Она действует на номерные названия; при названии текстом реплики сохраняется текст. Экспорт всех реплик остаётся с прежней нумерацией.

Файл имеет расширение `.csv`, но поля разделены **табуляцией**:

```text
Name    Start    Duration    Time Format    Type    Description
```

Используются `decimal`, тип `Cue`, минуты/секунды/миллисекунды и UTF-8 без BOM, как в приложенном конвертере. Кавычки экранируются. Пересекающиеся реплики остаются отдельными маркерами; время не меняется. Порядок соответствует документу.

## Проверка в Audition

Откройте соответствующий звук или сессию и выберите **File → Import → Markers from File… (Alt+/)** и укажите CSV либо MP4 с метками. Проверьте несколько позиций, кириллицу и границы диапазонов. Плагин экспортирует только маркеры: он не переносит звук, не создаёт аудиоклипы и не управляет Audition.

Импорт меток из MP4 проверен непосредственно в Adobe Audition 2026. Структура CSV сохранена по вашему конвертеру DeCoCo.

## Настройки и удаление

Настройки хранятся в `Plugins\AuditionMarkers.settings.xml` внутри папки данных Classic. Общий `Settings.xml` не меняется; горячая клавиша по умолчанию не назначается во избежание конфликтов.

Для удаления закройте Classic и удалите `AuditionMarkers.dll`. Чтобы сбросить настройки, удалите и XML плагина. Экспортированные CSV сохраняются.

## Сборка

На Windows с .NET Framework 4.8 и установленным Classic:

```powershell
./build.ps1 -ClassicDirectory 'C:\Program Files\Subtitle Edit Classic' -Test
```

Результат — `dist\AuditionMarkers.dll`. NuGet и Python не нужны. Тесты проверяют форматы, тайминги, кавычки, выбранные строки и безопасность записи. `tests/HostIntegration.cs` — проверка кнопки в обновлённом Classic; запускать только с изолированными тестовыми данными.
